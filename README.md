# 포켓몬 타워 디펜스

잡고 · 키우고 · 진화시키는 타워 디펜스. 순수 HTML + CSS + ES 모듈이라 **빌드 과정이 없다**.
서버 코드가 없고, 저장은 브라우저 localStorage를 쓴다.

- 포켓몬 50종 (1~5세대) / 스테이지 20개 (5개 지방 × 4)
- 진행도는 브라우저마다 따로 저장된다 (기기·브라우저를 옮기면 처음부터)
- 혼자 하는 판은 외부 요청이 0건이다. 아래 대결 모드를 열 때만 라이브러리 하나를 받아온다.

---

## 게임 구조

**진화는 원작 그대로 3단계다.** 파이리 → 리자드 → 리자몽.
1차진화에는 **이상한사탕**, 최종진화에는 **진화의돌**이 든다.
14개 라인(=42종)에 **메가진화 8종**을 더해 50종.

**메가진화는 혼자서는 못 한다.** 원작에서 메가진화가 트레이너와의 유대로 발동하듯,
이 게임에서는 **인접한 동료와의 유대**가 그 자리를 대신한다 — 상하좌우로 맞닿은
최종진화 2기 + 메가스톤으로 메가 1기가 된다. 슬롯은 줄지만 훨씬 강해진다.
리자몽만 파트너에 따라 **X와 Y로 갈린다** (원작에서 메가가 두 종류인 게 리자몽뿐이라서).

배치가 곧 퍼즐인 이유는 **바로 옆 8칸**이 값을 바꾸기 때문이다.

| 타입 | 인접 규칙 |
|---|---|
| 드래곤 | 뭉칠수록 강해진다 (인접 아군 1기당 공격력 +9%) |
| 격투 | 이웃에게 공격 속도 +7% |
| 에스퍼 | 이웃에게 사거리 +6% |
| 고스트 | 떨어질수록 강해진다 (인접 빈칸 1칸당 공격력 +11%) |
| 강철 | 강철끼리 이어야 광역·관통 +12% |

타입 상성은 원작 스타터 3각이다 — **불꽃 ▶ 풀 ▶ 물 ▶ 불꽃** (유리 ×1.5 / 불리 ×0.6).

## 친구와 대결 (1:1)

타이틀 화면의 **친구와 대결**에서 방을 만들면 6글자 코드가 나온다. 친구가 그 코드로 참가하면 시작.

- **방 코드가 곧 시드다.** 같은 코드로 들어온 두 사람은 포획·특성·드랍이 완전히 똑같이 나온다.
  적 편성은 원래부터 웨이브 번호로만 정해지므로 오는 적도 같다. 남는 건 **어떻게 배치하고 무엇에 쓰느냐**뿐.
- 각자 자기 브라우저에서 자기 판을 돌린다. 1초에 한 번 상대 진행 상황만 주고받으므로
  랙이 나도 판이 깨지지 않고, 연결이 끊겨도 내 판은 그대로 굴러간다.
- 더 높은 웨이브까지 버틴 쪽이 승리. 같으면 남은 라이프로 가른다.
- 대결 판은 이어하기로 저장되지 않는다 (같은 운을 두 번 쓰게 되므로).

접속 방식은 둘 중에 고른다.

| | |
|---|---|
| **다른 기기 · 인터넷** | WebRTC로 두 브라우저가 직접 연결된다. 상대를 찾는 순간에만 PeerJS 공개 브로커를 쓰고, 그 뒤 오가는 데이터는 서버를 거치지 않는다. |
| **같은 컴퓨터 · 창 2개** | 같은 브라우저에서 탭을 하나 더 열어 같은 코드로 참가. 네트워크를 전혀 쓰지 않는다. |

## ⚠️ 먼저 알아둘 것 — 압축해서 보내면 안 열린다

`index.html`을 더블클릭하거나 압축을 풀어 열면 **빈 화면**이 나온다.
ES 모듈(`<script type="module">`)은 브라우저 보안 규칙상 `file://` 에서 로드되지 않는다.
반드시 **웹 주소(http/https)로 서비스**해야 한다. 아래 방법 중 하나를 쓰면 된다.

---

## 방법 1. Netlify Drop — 가장 빠름 (1분, 계정 없이 시작)

1. https://app.netlify.com/drop 접속
2. `pokemon-td` **폴더째로** 드래그해서 놓기
3. 바로 `https://무작위이름.netlify.app` 주소가 나온다 → 친구에게 전달

무료 계정을 만들면 주소를 고정하고 이름도 바꿀 수 있다.
파일을 고친 뒤에는 폴더를 다시 드래그하면 갱신된다.

## 방법 2. GitHub Pages — 주소가 안 바뀜, 버전 관리까지

```bash
cd D:/poly/pokemon-td
git push -u origin main
```

그다음 GitHub 저장소 → **Settings → Pages → Source: `main` / `(root)`** 저장.
1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열린다.
(하위 경로 배포도 정상 동작하도록 모든 경로가 상대경로로 되어 있다.)

## 방법 3. Vercel

저장소를 연결해 두면 push 할 때마다 자동 배포된다.

## 방법 4. 같은 와이파이에 있을 때만 — 내 PC에서 바로

```bash
cd D:/poly/pokemon-td && py -m http.server 8080 --bind 0.0.0.0
```

내 PC의 IP를 확인해서(`ipconfig`) 친구에게 `http://<내IP>:8080` 을 알려준다.
내 PC가 켜져 있고 같은 네트워크일 때만 되며, 방화벽에서 8080 허용이 필요할 수 있다.

## 로컬에서 실행 (개발용)

```bash
cd D:/poly/pokemon-td && py -m http.server 5175
```

브라우저에서 `http://localhost:5175` 접속.

## 참고

- **모바일**: 레이아웃은 좁은 화면까지 대응돼 있고 터치로도 조작된다. 다만 보드가 작아지므로 가로 화면을 권한다.
- **저장 데이터 초기화**: 타이틀 화면 오른쪽 아래 `진행도 초기화`.
- **탭을 뒤로 보내면 게임이 멈춘다**: 브라우저가 배경 탭의 렌더 루프를 세우기 때문이다.
  대결에서는 각자 자기 판을 돌리고 승부는 도달 웨이브로 가르므로 유·불리가 생기지 않는다.
- **IP**: 포켓몬 이름·색·도트는 전부 `src/data/monsters.js`, `src/data/enemies.js`,
  `src/render/monsterSprites.js` 에만 있다. 도트는 원본을 옮긴 것이 아니라 알아볼 수 있는
  특징만 살려 새로 찍은 것이지만, 이름과 형상은 여전히 원작을 참조한다.
  개인적으로 친구들과 돌려보는 범위를 넘어 **공개 배포하거나 수익화할 계획이라면**
  이 세 파일의 이름·외형을 오리지널로 교체해야 한다.
